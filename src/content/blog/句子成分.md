## 二、复合句与简单句

:::tip[核心认识]
复合句不是凭空出现的，它是由简单句一步步扩展出来的。
:::

### 简单句核心

- 主语
- 谓语
- 宾语
- 宾补
- 定语
- 状语

### 造句只看两件事

1. 知道一个句子由哪几部分构成。
2. 知道这些部分该放在什么位置、按什么顺序出现。

:::caution[规律]
- 只要有名词，通常就会带定语。
- 一个完整句子必须有谓语动词。
- 状语出现频率也非常高。
:::
## 三、句子成分
句子成分常见 8 类：**主语、谓语、宾语、表语、补语、定语、状语、同位语**。  
当前先抓：**主语 + 谓语**。

| 成分 | 作用 | 常见表现 |
| --- | --- | --- |
| 主语 | 句子主要讲谁或什么 | 名词、代词、不定式、从句 |
| 谓语 | 说明主语做什么或是什么 | 动词、系动词结构 |
| 宾语 | 动作的承受者 | 名词、代词、从句 |
| 表语 | 说明主语的身份或状态 | 名词、形容词、介词短语等 |
| 补语 | 补充说明主语或宾语 | 形容词、名词、不定式等 |
| 定语 | 修饰名词 | 形容词、名词、短语、从句 |
| 状语 | 说明时间、地点、方式、原因等 | 副词、介词短语、从句 |
| 同位语 | 对前面的名词进一步解释 | 名词、短语、从句 |

### 1.主语(Subject)

:::note[定义]
主语就是一句话主要叙述的对象，也就是这句话主要在讲谁、讲什么。
:::

能充当主语的成分有：名词、代词、数词、动词不定式、动名词、句子(主语从句)、其它(名词化结构)
可以做主语的词类：

#### 1.名词作主语

>**所有名词都可以作主语。**

名词是**世间万物的名称**：
- 人：`teacher`
- 地名：`China`
- 事物：`apple`
- 看不见的东西：`air wind voice`

例：
```text
The apple is red.
Apples are sweet.
```

#### 2.代词作主语

:::note[定义]
代词是为了避免重复而代替名词的词。
:::

最常见的是**人称代词**和**指示代词**。

##### 人称代词

<details>
<summary>人称代词：主格 / 宾格(主格才可以作主语，宾语不可以)</summary>

| 主格 | 宾格 |
| --- | --- |
| I | me |
| we | us |
| you | you |
| she | her |
| he | him |
| it | it |
| they | them |

</details>


规律：
- 动词前面 → 主格  
- 动词后面 → 宾格

```text
I like her.
She likes me.
```
##### 指示代词

**指示代词**：this that
例：
```text
This is good.
That is mine.
```

#### 3.数词作主语

- 基数词：`one` `two` `three`
- 序数词：`first` `second` `third`

例：

```text
Three is enough.
The first is mine.
```

#### 4.动词不定式
动词原形不能直接作主语。必须变成非谓语动词。
- 不定式 (to do)
- 动名词 (doing)

例如: `To learn English is important`

#### 5.动名词
动词 + ing
例如：`Learning English is interesting.`

#### 6.句子
句子也可以作主语。这种句子叫**主语从句**
例如：`What he said is true.`

#### 7.其他(形容词名词化)

结构: 定冠词the + 形容词
例如：`the rich ` `the poor` `the old`
例子：`The rich are not always happy.`

#### 总结
只有以下内容可以作主语：
1. 名词
2. 代词(人称代词的主格/指示代词)
3. 数词(基数词和序数词)
4. 不定式
5. 动名词
6. 句子
7. 名词化结构
以下不能**不能直接作主语**：谓语动词 形容词 介词 副词

### 2. 谓语（Predicate）

:::note[定义]
谓语用来说明主语的动作、状态或特征。一个完整句子，核心一定离不开谓语。
:::

#### 谓语先分两类

| 类型 | 作用 | 典型结构 |
| --- | --- | --- |
| 动作型谓语 | 说明主语做什么 | 主语 + 动词 + 其他 |
| 状态型谓语 | 说明主语是什么 / 怎么样 | 主语 + 系动词 + 表语 |

#### 动作型谓语

动作型谓语表示主语发出的动作，比如：`eat` `play` `think` `like`。

##### 动词
动词：表示心理行为或动作的词语 `like ` `think` `play`等等

##### 简单谓语

由**实义动词**或**动词短语**构成。
**谓语中心只有一个动词**

- 实义动词：`She reads books.`
- 动词短语：`look after` `listen to` `take care of`

例：

```text
She looks after the child.
```
##### 复合谓语

**谓语中心不只有一个动词**

复合谓语 = **简单谓语 + 其他助动成分**。常见有 3 种：

1. **情态动词 + 实义动词或者动词短语的原型**  
   例如：`can speak` `must study` `will go`
2. **助动词 + 实义动词或者动词短语的原型**  
   例如：`do like` `does work` `did go`
3. **助动词 + 其他动词形式**  
   例如：`is reading` `has finished` `will be studying`

例：

```text
She can swim.
She is reading now.
```


#### 状态型谓语

说明 主语是什么、怎么样。

基本结构是：
```text
主语 + 系动词 + 表语
```

最常见的系动词是 **be 动词**。

| be 动词形式 |
| --- |
| be |
| am |
| is |
| are |
| was |
| were |
| being |
| been |

例句：

```text
I am happy.
She is beautiful.
They are students.
```

#### 表语

表语放在**系动词后面**，说明主语的身份、特征或状态。

能作表语的常见成分：

- 名词
- 形容词
- 介词短语
- 不定式
- 动名词
- 代词
- 数词
- 分词
- 副词
- 句子

例：

```text
She is a teacher.
She is happy.
She is at home.
My job is to teach.
```

---

:::tip[英语句子核心其实只有两种]
1. **动作句**：主语 + 动词 + 其他  
   例：`She reads books.`
2. **状态句**：主语 + 系动词 + 表语  
   例：`She is happy.`
:::

复习时反复看这三件事：

- 主语是谁
- 谓语在哪
- 这是动作句还是状态句

后面学时态、从句、长难句，本质上都是在这个骨架上继续加东西。
