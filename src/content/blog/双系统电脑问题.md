# 解决 Ubuntu + NVIDIA 显卡桌面亮度滑条 / Fn 亮度键不生效

在部分 Ubuntu 系统中，安装 **NVIDIA 驱动**后可能出现：无法调节屏幕亮度

原因通常是 **NVIDIA 驱动默认关闭亮度控制接口**。  
可以通过 **Xorg 配置启用 EnableBrightnessControl** 解决。

---

## 一、确认当前使用 X11

首先确认系统使用的是 **Xorg 会话**：

```bash
echo $XDG_SESSION_TYPE
```

如果输出：

```text
x11
```

说明可以继续下面步骤。

如果是：

```text
wayland
```

需要切换到 **Xorg 登录会话**。

---

## 二、查看 NVIDIA Xorg 配置文件

检查系统是否存在 NVIDIA 配置：

```bash
ls -la /usr/share/X11/xorg.conf.d | grep -i nvidia
```

示例输出：

```text
10-nvidia.conf
```

说明系统已加载 NVIDIA Xorg 配置。

---

## 三、创建本地 Xorg 配置文件

不要直接修改 `/usr/share/X11` 目录文件（系统更新可能覆盖），  
推荐在 `/etc/X11/xorg.conf.d/` 创建覆盖配置。

### 1 创建目录

```bash
sudo mkdir -p /etc/X11/xorg.conf.d
```

---

### 2 创建配置文件

```bash
sudo gedit /etc/X11/xorg.conf.d/90-nvidia-brightness.conf
```

写入以下内容：

```txt
Section "Device"
    Identifier "Nvidia Card"
    Driver "nvidia"
    Option "RegistryDwords" "EnableBrightnessControl=1"
EndSection
```

重启系统

```bash
sudo reboot
```

---

## 五、验证配置是否生效

系统启动后执行：

```bash
grep -i EnableBrightnessControl /var/log/Xorg.0.log
```

如果看到：

```text
Option "RegistryDwords" "EnableBrightnessControl=1"
```

说明配置成功加载。

---

## 总结

解决 NVIDIA 驱动导致的亮度控制问题步骤：

1. 确认使用 **X11**
2. 创建 **/etc/X11/xorg.conf.d/** 配置
3. 启用 **EnableBrightnessControl=1**
4. 重启系统
5. 验证 Xorg 日志
6. 测试 Fn 键和亮度滑条

即可恢复亮度控制功能。
