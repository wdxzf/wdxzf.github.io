## 一、常用 Markdown

### 1. 标题

模板：

```md
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

效果：

<h1>一级标题示例</h1>
<h2>二级标题示例</h2>
<h3>三级标题示例</h3>
<h4>四级标题示例</h4>

## 三、Frontmatter 与文章模板

### 1. 最小可用模板

模板：

````md
---
title: "文章标题"
description: "一句话概括本文内容"
date: 2026-03-11
category: [markdown]
tags: [写作]
---

## 一、前言
````

### 2. 常用完整版模板

模板：

````md
---
title: "文章标题"
description: "一句话概括本文内容"
date: 2026-03-11
lastModified: 2026-03-11
category: [markdown]
tags: [astro, 写作, 博客]
series: "Astro 写作"
seriesOrder: 1
mathjax: false
mermaid: false
draft: false
sticky: 0
comment: true
donate: false
slug: "custom-slug"
ogImage: "/images/cover.svg"
---

## 一、前言
````

### 3. 字段速查表

| 字段 | 作用 | 说明 |
| --- | --- | --- |
| `title` | 标题 | 必填 |
| `description` | 摘要 | 建议必填 |
| `date` | 发布时间 | 必填 |
| `lastModified` | 最后修改时间 | 不写会回退到文件修改时间 |
| `category` | 分类 | 建议 1 个主分类 |
| `tags` | 标签 | 建议写检索词 |
| `series` | 系列名 | 系列文章时填写 |
| `seriesOrder` | 系列顺序 | 系列文章时填写 |
| `draft` | 草稿 | `true` 时生产环境不发布 |
| `sticky` | 置顶值 | 数值越大越靠前 |
| `toc` | 目录 | 默认开启，想关闭时写 `toc: false` |
| `comment` | 评论区 | 按文章控制 |
| `donate` | 赞赏区 | 按文章控制 |
| `mathjax` | 公式渲染 | 有公式时开启 |
| `mermaid` | 图表渲染 | 有图表时开启 |
| `slug` | 固定链接 | 需要自定义链接时填写 |
| `ogImage` | 分享图 | 封面文章建议填写 |

### 4. 文章页控制项示例

模板：

```yaml
toc: false
comment: true
donate: false
series: "Astro 写作"
seriesOrder: 2
```

效果：

- `toc: false`：文章页不显示目录
- `comment: true`：文章页底部会显示评论区
- `donate: false`：文章页不显示赞赏区
- `series + seriesOrder`：文章页底部会显示系列文章导航

## 四、写作时自动生效的功能

### 1. 图片懒加载与点击预览

模板：

```md
![ROS 航点导航示意图](/images/ros-waypoints/cover.svg)
```

效果：

![ROS 航点导航示意图](/images/ros-waypoints/cover.svg)

说明：

- 图片会自动懒加载
- 图片支持点击预览
- 能识别尺寸时会自动补宽高

### 2. 外部链接自动新开标签页

模板：

```md
[Astro 官网](https://astro.build)
```

效果：

[Astro 官网](https://astro.build)

说明：正文中的外部链接会自动带上新标签页和安全属性。

### 3. 阅读时间、字数、最后修改时间自动显示

模板：

````md
---
title: "文章标题"
description: "文章摘要"
date: 2026-03-11
---
````

效果：

- 文章标题下方会自动显示发布时间
- 会自动计算阅读时间和字数
- `lastModified` 不写时会自动回退到文件修改时间

### 4. 草稿与置顶

模板：

```yaml
draft: true
sticky: 10
```

效果：

- `draft: true`：开发环境可见，生产构建不发布
- `sticky: 10`：在文章列表里更靠前

### 5. 图片路径写法

模板一：`public` 目录绝对路径

```md
![封面图](/images/2026-1-23-git_code/cover.svg)
```

模板二：文章目录相对路径

```md
![配图](images/文章名/image.png)
```

说明：

- 公共资源更适合放 `public`
- 文章专属截图可以跟文章一起管理
- `alt` 文本尽量写清楚
