VS Code 文件单击会被替换，是因为开启了 预览模式。
在 VS Code 中，单击文件会以预览模式打开，这意味着下一个单击的文件会替换当前预览的文件。如果你想固定打开一个文件，可以双击它，这样它就会在标签栏中保持打开状态，不会被下一个单击的文件替换。

如果想取消，将其关闭即可。

1. 关闭右侧代码缩略图
右边那条小代码地图很占空间。
设置里搜索：minimap
关闭：Editor › Minimap: Enabled

1. 关闭面包屑导航
代码上面这行：
Core > Src > main.c > main可以关掉。
设置搜索：breadcrumbs
关闭："breadcrumbs.enabled": false

1. 开启禅模式
写代码时可以按：Ctrl + K，然后按 Z进入 Zen Mode / 禅模式。它会隐藏很多干扰界面，适合看代码。
退出按：Esc 两次
