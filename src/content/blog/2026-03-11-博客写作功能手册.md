## 一、常用 Markdown

### 标题

```md
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

### 分割线

```md
---
```

---

### 强调

```md
**加粗**  *斜体*  ~~删除线~~
```

**加粗** *斜体* ~~删除线~~

### 引用

```md
> 这是一级引用
>
> > 这是二级引用
```

> 这是一级引用
>
> > 这是二级引用

### 脚注

```md
这是一句带脚注的话[^1]

[^1]: 这是脚注内容
```

### 列表与任务列表

```md
- 无序列表项
- 第二项

1. 有序列表项
2. 第二项

- [x] 已完成
- [ ] 未完成
```

### 行内代码与代码块

````md
行内代码：`const title = "hello"`

```js
const title = "hello";
console.log(title);
```
````

### 表格

```md
| 字段 | 含义 |
| --- | --- |
| title | 文章标题 |
| date | 发布时间 |
```

| 字段 | 含义 |
| --- | --- |
| title | 文章标题 |
| date | 发布时间 |

### 链接

```md
[外部链接](https://astro.build)
[站内链接](/about)
```

### 图片

```md
<!-- public 目录（公共资源） -->
![封面图](/images/文章名/cover.svg)

<!-- 文章目录相对路径（文章专属截图） -->
![配图](images/文章名/image.png)
```

:::tip[图片路径说明]
- 文章专属截图建议放 `src/content/blog/images/<slug>/`，用相对路径引用
- 公共资源（多篇文章共用）放 `public/images/`，用绝对路径引用
- `alt` 文本尽量写清楚，兼顾无障碍访问
:::

### HTML 注释

```md
这行会显示
<!-- 这行不会显示 -->
这行也会显示
```

## 三、Frontmatter 字段速查

| 字段 | 作用 | 说明 |
| --- | --- | --- |
| `title` | 标题 | 必填 |
| `date` | 发布时间 | 必填，格式 `YYYY-MM-DD` |
| `description` | 摘要 | 建议必填，不要用占位文本 |
| `lastModified` | 最后修改时间 | 不填时回退到文件修改时间 |
| `category` | 分类 | 建议 1 个主分类，写数组 |
| `tags` | 标签 | 写检索词，写数组 |
| `series` | 系列名 | 系列文章时填写 |
| `seriesOrder` | 系列顺序 | 系列文章时填写 |
| `draft` | 草稿 | `true` 时生产环境不发布 |
| `sticky` | 置顶权重 | 数值越大越靠前 |
| `toc` | 目录 | 默认开启，`false` 关闭 |
| `comment` | 评论区 | 默认开启，`false` 关闭 |
| `donate` | 赞赏区 | 按文章控制 |
| `mathjax` | 公式渲染 | 有公式时设为 `true` |
| `mermaid` | 图表渲染 | 有图表时设为 `true` |
| `slug` | 固定链接 | 自定义 URL 时填写，建议英文 |
| `ogImage` | 社交分享图 | 封面文章建议填写 |

## 四、写作模板

### 最小可用模板

```md
---
title: "文章标题"
description: "一句话概括本文内容"
date: 2026-04-14
category: [分类]
tags: [标签]
slug: "custom-slug"
---

## 一、前言
```

### 完整模板

```md
---
title: "文章标题"
description: "一句话概括本文内容"
date: 2026-04-14
lastModified: 2026-04-14
category: [分类]
tags: [标签1, 标签2]
series: "系列名"
seriesOrder: 1
mathjax: false
mermaid: false
draft: false
sticky: 0
toc: true
comment: true
donate: false
slug: "custom-slug"
ogImage: ""
---

## 一、前言

## 二、正文

:::tip[提示]
这里写重点内容
:::
```

## 五、写作时自动生效的功能

- **图片懒加载与点击预览**：图片自动懒加载，支持点击放大，能识别尺寸时自动补宽高
- **外部链接新标签页**：正文中外部链接自动加 `target="_blank"` 和安全属性
- **阅读时间与字数**：标题下方自动计算显示
- **最后修改时间**：`lastModified` 不填时自动回退到文件修改时间
