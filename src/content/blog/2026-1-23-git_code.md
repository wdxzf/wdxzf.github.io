# Git 简单笔记

![Git 使用封面图](/images/2026-1-23-git_code/cover.png)

## 1. 最基础的工作流

![Git 基本流程](/images/2026-1-23-git_code/workflow.png)

三步走：**工作区 → 暂存区 → 仓库**。

```bash
git init                   # 初始化仓库
git status                 # 查看当前状态
git add .                  # 添加到暂存区
git commit -m "消息内容"   # 提交到本地仓库
```

---

## 2. 常用配置

```bash
git config --global user.name "Your Name"       # 配置用户名
git config --global user.email "you@example.com" # 配置邮箱
```

---

## 3. 分支（够用版）

```bash
git checkout -b feature/login # 新建并切换分支
git checkout main             # 切回主分支
git merge feature/login       # 合并分支
```

---

## 4. 远程协作（最常用）

```bash
git remote add origin git@github.com:your/repo.git # 绑定远程仓库
git push -u origin main                            # 首次推送并关联
git pull                                           # 拉取远程更新
```

---

## 5. 撤销与回滚（常见场景）

| 场景 | 命令 | 说明 |
|---|---|---|
| 修改了文件但不想要 | `git checkout -- file` | 回到上次提交 |
| 已 add 但不想提交 | `git reset file` | 从暂存区移出 |
| 提交错了 | `git revert <commit>` | 生成反向提交 |

---

## 6. .gitignore

## 7. 快速命令清单

```bash
git status                 # 查看当前状态
git add .                  # 添加到暂存区
git commit -m "msg"        # 提交到本地仓库
git checkout -b feat/xxx   # 新建并切换分支
git merge feat/xxx         # 合并分支
git pull                   # 拉取远程更新
git push                   # 推送到远程仓库
```
